# Security policy

## Supported versions

Security fixes are applied to the latest release. Older releases are not guaranteed to receive patches.

## Report a vulnerability

Use GitHub's **Security** tab and select **Report a vulnerability** to open a private security advisory. Do not file a public issue for exploitable command execution, prompt injection, path traversal, credential exposure, unsafe downloads, or dependency compromise.

Include the affected version, threat model, reproduction, impact, and a safe proof of concept. Maintainers will acknowledge valid reports as soon as practical, coordinate a fix and disclosure window, and credit the reporter unless anonymity is requested.

## Scope

The project includes executable scripts and instructions consumed by capable agents. Treat third-party skills, web content, downloaded media, target repositories, and generated shell commands as untrusted until reviewed. Landing Studio does not ask contributors or users to disclose secrets for diagnosis.
