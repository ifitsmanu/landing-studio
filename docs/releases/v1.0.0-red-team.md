## Release gates

- 18 Agent Skills and 191 repository files validate; generated run evidence is excluded.
- 49 of 49 automated tests pass.
- 9 of 9 deterministic cases and 83 of 83 weighted assertions pass.
- The positive browser fixture passes across responsive, dark, and reduced-motion profiles.
- The release workflow repeats the fixture in Chromium and WebKit before publishing assets.
- Motion syntax and deterministic capture/encode regressions pass.
- Claude plugin validation, OpenAI skill metadata, CFF, shell checks, dependency audits, secret scanning,
  GitHub Actions static analysis, and Git diff checks pass.
- No open P0 or P1 freeze finding remains.

## Retained limitations

1. Zero clean-context model/runtime executions are retained, so activation, instruction following,
   taste, research quality, and model-operated browser behavior remain unproven.
2. The repository includes a QA fixture, not a polished real-client landing-page case study.
3. Chromium is the pull-request floor. WebKit is a tag-release gate. Firefox and physical devices are
   conditional project evidence.
4. Gemini, Copilot, OpenCode, Cursor, Windsurf, and Cline paths follow current official conventions,
   but native discovery and output have not been smoke-tested for every runtime.
5. WebGL/3D provides selection and acceptance methodology without an executable reference scene.
6. Reviewer independence is enforced through contract ordering and identity fields, not external
   identity attestation.
7. v1 does not provide signed tags, an SBOM, or build provenance attestations.

## Release decision

Ship v1.0.0 as a strong, honest open-source foundation. Do not market it as cross-model proven or as
demonstrated exceptional output until retained behavioral runs and category-diverse public case
studies exist.
