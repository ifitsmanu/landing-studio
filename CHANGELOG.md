## [1.0.0] - 2026-07-15

### Added

- Portable Agent Skills core with documented Claude Code, Codex, Gemini CLI, Cursor, GitHub Copilot, and OpenCode paths.
- Persistent page and per-section run state, approval locks, artifact hashes, and release blocking.
- Approved page frames, explicit capability/skipped-section decisions, controlled backflow, and immutable finding identities.
- Creative direction, media sourcing, technology curation, WebGL/3D, and independent landing red-team specialists.
- Executable browser evidence harness with accessibility, responsive, journey, console, request, screenshot, and trace artifacts.
- Machine-readable page-frame, evidence, creative, media, dependency, implementation, browser, page-audit, and review contracts.
- Portable evidence export with checksums, containment enforcement, and symlink-safe artifact handling.
- Open-source governance, contribution, security, CI, release, and community files.

### Changed

- Reworked the director from whole-page approval to one-section-at-a-time production.
- Replaced shape-only validation and manual-only eval claims with parsed contracts and executable checks.
- Made full-page browser, search, and fresh-context red-team audits independent release gates.
- Added Chromium and WebKit verification to immutable tag releases.
- Corrected motion capture poster, output-dimension, virtual-time timeout, and end-to-end command defects.

### Security

- Added explicit untrusted-web-content boundaries and rights/provenance gates.
- Rejected artifact paths that escape the project root through traversal or symlinks and blocked finding-ID collision/downgrade attacks.
- Added private vulnerability reporting through GitHub Security Advisories.
