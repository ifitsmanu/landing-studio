# Roadmap

The roadmap is ordered by evidence and contributor demand, not dates.

## v1 foundation

- Portable Agent Skills core and runtime compatibility evidence.
- Persistent section-by-section studio state.
- Rights-first media, dependency proof, 3D/WebGL, browser QA, and independent red team.
- Executable validation, fixtures, CI, release artifacts, and honest scorecard.

## Next

- Retained cross-model activation and outcome benchmarks.
- More category-diverse public example projects with licensed assets.
- Optional MCP service for remote browser/media infrastructure and team run history.
- Community library adapters and installation registry integrations where official submission paths exist.
- Longitudinal conversion experiment templates based on first-party data rather than universal benchmarks.

Requests should include a concrete user problem, current workaround, proof that it recurs, proposed acceptance test, maintenance cost, and privacy/security implications.
