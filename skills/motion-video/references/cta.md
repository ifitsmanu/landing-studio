# CTA: connect attention to the next step

The motion asset's CTA must honor the approved campaign/page promise and lead to a destination that
does what the label says.

## Primary-path default

Use one visually primary CTA by default because it creates clear hierarchy and measurement. A
subordinate secondary path is valid for a genuine multi-stage buying journey, such as self-serve plus
sales, product plus documentation, or video plus full case study. Do not claim a universal conversion
penalty for multiple actions; verify the chosen hierarchy from first-party behavior.

Record:

- label and destination;
- audience awareness and placement;
- expected post-click state;
- secondary action, if any, and why it cannot be deferred;
- analytics event and attribution convention;
- owner and approval.

## Message match

The pre-view promise, film claim, CTA label, destination headline, form/flow, and success state must
describe the same journey. Examples:

- “Start free” reaches a real self-serve start, not an unannounced sales form.
- “Watch the demo” opens the promised demo, not a pricing page.
- “Read the docs” opens relevant documentation, not a generic homepage.
- A command CTA is runnable and current.

Broken message match is a trust and conversion defect even when click-through rate looks strong.

## Presentation

For a dedicated end state, use real brand assets, high contrast, final-size legibility, and enough
hold time for the actual label/destination. Determine timing by playback test, not a fixed minimum.
The website version should normally rely on a real accessible button adjacent to media instead of
burning a fake interactive button into video.

Place the CTA where the audience can act. A longer asset may repeat the same primary path after a
proof moment and at the end; a short ad may use the platform-native button and final frame. Measure
the placement rather than assuming a mid-roll always wins.

## Platform handoff

Pair the asset with the platform's native action where applicable:

| Placement | Recommended action carrier |
|---|---|
| Web hero | Accessible page button adjacent to the poster/loop |
| Embedded film | Visible page CTA plus approved end state |
| Social/paid | Platform CTA and message-matched link; end state when useful |
| YouTube | Description/end screen/pinned comment as appropriate |
| Keynote/press | Readable destination plus speaker/press-kit handoff |
| Email | Linked poster and real HTML button |

Verify current platform capabilities before specifying them.

## Measurement

- Use project-standard campaign parameters or short links without breaking canonical attribution.
- Track eligible views/exposure separately from CTA click and completed conversion.
- Segment by placement/creative only when the sample supports a decision.
- Check downstream quality and guardrails; clickbait can improve clicks while harming outcomes.
- Respect consent and do not encode sensitive information in URLs.
- Test redirects, deep-link fallback, mobile behavior, and expiry.
