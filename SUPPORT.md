# Support

- Use GitHub Discussions for installation help, workflows, showcases, and design/copy questions.
- Use GitHub Issues for reproducible defects, compatibility failures, and scoped feature proposals.
- Use GitHub Security Advisories for vulnerabilities or sensitive conduct reports.

Include the Landing Studio version, agent/runtime and version, operating system, installation method, exact command or prompt, relevant logs with secrets removed, and the smallest reproducible example.

Community support is best-effort. The Apache-2.0 license does not include a warranty or service-level agreement.
